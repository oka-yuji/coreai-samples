# Native complex candidate decision

The native-complex candidate is selected for continued iPhone integration. It preserves the frozen numerical contract and the exact saved gallery previously accepted by the owner, while reducing loaded DiT footprint enough for complete main-app generation and editing. This is not performance, calibrated-budget or ordinary Models acceptance.

| Acceptance ID | Evidence and result |
|---|---|
| QNC-01 | `test_image_native_complex.py` and component compression inventories preserve source, precision, group16, the 56 F16-stored Linear weights, shape and schedule. Only the rotary implementation selection changes; the older candidate remains available. |
| QNC-02 | [Complete Mac record](qwen-image21-native-complex-20261029.json): all 1,230 fixed and 120 final comparisons pass the frozen gates. Independent raw/public audits passed, and all 180 saved final C latent/RGBA/PNG files match the previous candidate byte for byte. |
| QNC-03 | [Original main-app record](qwen-image21-native-complex-device-20261029.json): generation and editing finish on iPhone18,1 / 24A446. Generation takes 336.33 seconds with DiT loaded footprint 807,460,152 B. Editing finishes but fails fidelity because the PNG input loses hidden RGB. The failure remains recorded and is corrected independently in [#382 / PR #387](https://github.com/oka-yuji/coreai-samples/pull/387). No production budget is inferred. |
| QNC-04 | [Exact gallery equivalence proof](qwen-image21-native-complex-visual-equivalence-20261029.json): all 240 output PNG pairs, 510 gallery images including references, inputs and visible presentation match the original owner-reviewed content. The unchanged [owner feedback](qwen-image21-owner-quality-20261028.json) applies to those same images; no new human review or benchmark score is generated. |

The corresponding child change records the corrected iPhone generation/editing final latent and RGBA checks. The original raw manifest remains immutable with its original `device_verification=pending` creation state; later device evidence binds its SHA separately. The provisional warm 60/90-second goal, phase memory calibration, continuous use and ordinary Models operation remain open under #219, #220 and #221.

The implementation and converter identity, numerical evidence, gallery proof and acceptance guard belong together because a candidate cannot be accepted from the code change alone. The measured handwritten implementation delta is 299 lines (278 added, 21 removed), versus the initial 150–300-line estimate. Separate totals are 381 test lines, 2,948 generated recipe lines and 6,400 documentation/evidence lines before this decision note. The planned five-point unit and dependency order are retained.
