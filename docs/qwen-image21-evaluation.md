# Qwen Image evaluation contracts

This implements evaluation contracts for [#215](https://github.com/oka-yuji/coreai-samples/issues/215), under QMI practical v2. Mobile feasibility and image quality remain unverified.

The source is `Qwen/Qwen-Image-2.1-Turbo@fc13ba1986fcb905854dc8de2f52eee395f49b5b`, Diffusers `b800f828f3951c4d206e154411bcbfa693cd322e`. Use the locked recipe environment. Model jobs require the shared heavy-job lock. CPU contract validation and tokenizer/image fixture preparation do not execute learned networks.

## Frozen inputs

[`evaluation-cases.json`](../Tools/Conversion/recipes/qwen_image21/evaluation-cases.json) defines 15 generation and 15 editing inputs, each with seeds 20261018 and 20261021. Japanese and English cover objects, people, text, background changes, preservation and alpha. Editing inputs are original deterministic drawings, including an illustrated person. This does not establish photographic identity preservation.

```sh
QI_PYTHON="$PWD/.local/conversion/qwen_image21/.venv/bin/python"
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.fixtures \
  --definition Tools/Conversion/recipes/qwen_image21/evaluation-cases.json \
  --snapshot "$QI_SNAPSHOT" --output "$QI_FIXTURES"
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate \
  inventory "$QI_FIXTURES" "$QI_FIXTURES/fixtures.json"
```

Use a new directory. The inventory contains prompt bytes, authored PNGs, processed tokens, source template removal, text/multimodal positions, masks, expanded image-slot layout, VAE input and saved noise. `text-preprocessing.npz` uses zero vision embeddings deliberately: it verifies placement and preprocessing, not learned encoder outputs. General EXIF, tagged-color and resize boundaries belong to #217's additional goldens.

Noise is saved Float32 `[1,1024,64]`, generated by PyTorch 2.9.0 CPU `randn`, spatially packed in the original order. Matching a seed in a different RNG is not equality. Raw file SHA is part of each input record.

Reference/candidate records must match fixture ID, source revision, prompt/reference/noise SHA, processed-token SHA, layout SHA, operation and saved sigmas. Same-size edits, symbolic links and unsafe relative paths are rejected. Failed and unreviewed cases remain in the suite.

## Profile format 2

[`profile.py`](../Tools/Conversion/adapters/qwen_image21/profile.py) defines exact physical boundaries. [`validate_profile`](../Tools/Conversion/adapters/qwen_image21/evaluation.py) is the executable JSON contract.

| Field | Contract |
| --- | --- |
| `source` | Exact source/implementation revisions, dependency-lock SHA, converter file SHAs |
| `workload` | 512-square output/reference, batch one, at most one reference, text capacity 512, joint capacity 2304; 1536 is generation-only |
| `components` | All five: vision, text, denoiser, VAE encoder, VAE decoder; one stateless `main`, relative asset path, exact input/output names, shapes, dtype and layout |
| `compute_dtype` | Float32, Float16 or BFloat16 per component; independent of capture and physical I/O dtype |
| `weight_encoding` | Actual representation; the dense baseline records Float32 |
| `scheduler_compute_dtype` | Float32 Euler accumulation |
| `scheduler_output_dtype`, `cast_back` | Cast back to model-output dtype after **every** step |
| `rounding` | Nearest, ties to even |
| `denoiser_fp16_clip` | `[-65504,65504]`, applied by the original graph only on its FP16 path |
| `zero_centered_norm_dtype` | Float32 for source `weight + 1` normalization |
| `sigmas`, `terminal_sigma` | Saved eight sigmas, then zero; no implicit dynamic shift |
| `prefix_kv_cache` | `false`; unrelated to Core AI specialization caches |

`row-major` is the serialized host boundary, not an assumption about preferred NDArray strides. Native packing must honor actual descriptor strides. Indices remain Int32 and masks remain Bool when floating precision changes.

```sh
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate baseline-profile \
  --bundle "$QI_FP32_BUNDLE" \
  --dependency-lock Tools/Conversion/recipes/qwen_image21/uv.lock \
  --output "$QI_PROFILE"
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate profile "$QI_PROFILE"
```

The comparison profile hash uses canonical JSON SHA-256. Deployment identity instead hashes the **saved raw bytes** of `bundle.json`; that manifest is excluded from its internal asset inventory. #216 produces verified assets, and #263 pins the independently expected hash/inventory. A bundle's own `passed` field does not confer trust.

## Independent references and gates

```sh
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.suite_reference \
  --snapshot "$QI_SNAPSHOT" --fixtures "$QI_FIXTURES" \
  --precision fp32 --output "$QI_REFERENCE"
```

Run separately for `fp16` and `bf16` when evaluating them. The command uses the pinned original pipeline, records every output/latent SHA and repeats a generation and edit for repeatability. It owns the shared lock. `--run-ids` permits a limited diagnostic run; all other rows stay `not_run` and the suite stays incomplete. This trace run is not clean latency evidence.

| Comparison | Purpose |
| --- | --- |
| A0 FP32 ↔ A1 FP16 | Precision loss |
| A0 FP32 ↔ A1 BF16 | Precision loss |
| A1 FP16 ↔ A1 BF16 | Direct precision difference if both are evaluated |
| A1 ↔ B with the same precision | Quantization loss |
| B ↔ C with identical quantized weights and input | Conversion error |

The existing FP32 gate remains normalized maximum error ≤ 0.001 and normalized RMSE ≤ 0.0001. Denominators are `max(max(abs(reference)), 1e-12)` and `max(rms(reference), 1e-12)`. Nonfinite output fails. The block probes retain their failed FP32-gate results for FP16/BF16.

**New precision thresholds are not yet frozen.** Full-source repeatability and an explicit versioned threshold record are required before accepting a full quantized candidate. Block feasibility exploration is not threshold calibration or quality acceptance. #216 must not silently relax the FP32 gate or pool precision results.

Human ratings use 0 = failed, 1 = acceptable, 2 = good, null = unreviewed. Instruction, text, detail, preservation and alpha are separate applicable axes. The provisional target is ≥90% success on every applicable axis and at most two newly failing outputs among all 60. `quality_summary` preserves original failures and rejects missing rows/changed axes. Unreviewed ratings never pass; source limitations remain visible.

## Time and memory

The existing CLI accepts `--diagnostics off` or `trace`; default trace preserves earlier captures. Off writes final PNG and scalar metadata without intermediate tensor dumps. `measurement.seconds` begins before bundle hashing in the CLI and ends after the final image is saved. Legacy `seconds` retains its narrower function boundary. Preparation, loads, inference, individual DiT steps, release and saving use monotonic intervals.

Loading and first execution can include specialization. No separate specialization timer is exposed: `specialization_seconds` remains null/unavailable and load is labeled `load-including-specialization`. Subtracting timings is not a measured specialization cost.

Point observations separate RSS, footprint, graphics footprint and process-lifetime kernel peak. The macOS host cannot read an iOS app budget or observe the Core AI delegate's MTLDevice allocation counter, so both remain null/unavailable. `NSProcessInfo.thermalState` records actual thermal state. These values are not summed into “RAM,” and before/after samples are not phase peaks.

`live_memory_peak` unions declared allocation lifetimes, including old/new component load overlap. `storage_id` identifies an allocation, not an asset hash. Aliases count their backing storage once; disjoint lifetimes are not added. Unknown workspace/cache/activation categories leave `planning_peak_bytes` null while preserving the known contribution.

Aggregation partitions by profile/workload hash, device, OS build, route, operation, cache state, diagnostics, power and thermal state. Cache states are `uncached-cold`, `cached-cold`, `warm`, `continuous`. A group needs 20 completed samples for the sample-count flag. Quantiles use nearest-rank p50/p95 plus maximum. Failures, cancellations and unrun cases retain null completed latency and their outcome counts.

```sh
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate aggregate runs.json
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate memory allocations.json
"$QI_PYTHON" -m Tools.Conversion.adapters.qwen_image21.evaluate quality ratings.json
"$QI_PYTHON" -m unittest discover -s Tools/Conversion/tests -v
```
