モデル管理パネル

使うデモはそのままに、モデルの取得・登録・保存領域を管理する。共通macOS画面の「モデル管理…」から開く補助パネルの案です。

レビュー用の未確認案 · モデル名、パス、配布情報、容量、速度、進捗はすべて架空サンプルです。ネットワーク通信・ファイル選択・削除・モデル読み込みは実行しません。ここでのGBはダウンロード／ディスク容量で、メモリ使用量ではありません。

操作の違い

「モデルを削除」はダウンロードしたモデルと準備済みコピーを削除。「準備済みコピーを消去」は元のモデルを残し、次のロード時に準備し直します。「登録を外す」は一覧への登録だけを外し、ファイルを残します。

既存画面との対応

ModelsViewのCatalog・On this Mac・Storageを1枚に集約。CatalogRowViewの部分取得／再開／読込／削除と、FolderRowViewの準備済みコピー消去／登録解除を残します。OSのフォルダ選択はサンプルの選択シートで近似します。

今回の確認点

  • 一覧での取得状態と、実行中モデルの区別。
  • 「モデル削除」「準備済みコピー消去」「登録解除」の文言。
  • ロード完了後は選んだモデルのデモへ戻る導線。

「ロード」は明示操作で開始します。取得完了だけではロード・推論を始めません。実装では標準のパネル、削除確認、フォルダ選択、VoiceOverに対応します。
