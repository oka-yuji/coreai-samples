このデモについて

Mac版は入力が確定して300ms後に抽出する既存の操作を維持します。日本語入力の変換中は抽出しません。ラベル、フォーム、モード、フィルタを変えると、前の候補と人の確定をクリアします。このHTMLでは、その操作に合わせて固定候補を表示します。モデルの準備完了や、画面を開く・切り替えるだけでは結果を更新しません。

変換モデルの技術検証です。点検結果を自動で確定するものではありません。
既存の品質注記と、このサンプルの区別

ゼロショットの日本語点検メモ評価は事前基準に未達（B3）。既定のR1 + N1で評価した別の固定200件では、捏造候補13/200、主spanの適合率0.788、再現率0.822。これは既存実装に記録された評価結果で、このHTMLの測定ではありません。候補スコアは未校正です。

入力を編集するまで、抽出は始まりません。
