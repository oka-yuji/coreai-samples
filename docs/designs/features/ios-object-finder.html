機能画面案 02 · カメラ

言葉を決めて、
カメラを向ける。

開始するまでカメラは開かず、開始後はプレビューを主役に。検索中の言葉と入力中の言葉を区別し、切替の順序を見せます。

入力例 → マグカップ → 検索を開始。検索中に「鍵」へ編集し、切替／取消を試せます。状態メニューで権限と中断を確認できます。

  1. 開始は本人の操作で。 モデル取得の完了や画面の表示では撮影を開始しません。権限確認は「検索を開始」のあとです。
  2. カメラの結果を見失わない。 候補はプレビューの枠で示します。停止・切替中は枠を消し、候補がない場合も状態を文章で示します。
  3. 入力だけでは切り替えない。 検索中に編集すると「この言葉で検索」が現れ、旧検索の停止後に切り替わります。待ち時間中は変更を取り消せます。
  4. 設定は必要なときに。 表示基準は折りたたみ、停止中に変更。カメラ権限の拒否・中断・処理失敗は次にできる操作を添えます。

既存画面との対応

ObjectFinderView：任意語句、既存4例、開始／停止、検索中の変更、ライブプレビュー、閾値、権限とエラー。
ObjectFinderFeature：idle / starting / searching / stopping、restartAfterStop、通常停止／背景移行、0.30〜0.90の基準。

確認したい点

確認待ち：候補名・候補なしの補助文は、既存の枠表示に加える提案です。安定検出時の触覚通知は既存機能として維持し、HTMLでは再現しません。縦横回転、枠の追従と消滅、権限ダイアログ、VoiceOverは実機確認が必要です。

共通のモデル操作

タイトルはモデル名。短い説明と閉じた詳細解説を置きます。未取得でも説明とモデル情報は開け、入力・実行は無効です。取得→検査が完了しても、この画面で待ちます。削除は確認を経て、入力と結果を残します。

HIGを反映する範囲

標準の戻る、44px以上の操作領域、文字拡大と縦配置、明示的な開始・停止、進捗、失敗後の復帰を近似しています。ネイティブではNavigationStack、Dynamic Type、SF Symbols、システムの選択／権限画面を使います。HTMLのpx検査は実機のpt・読み上げ確認の代わりにはなりません。
