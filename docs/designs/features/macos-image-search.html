macOS 画像検索

モデルを左に残し、画像の選択と検索結果を並べて確かめる。

デザイン提案 · 2026-10-18　状態・画像・出力・類似度・時間は画面確認用のsampleです。実モデルの取得・推論・ファイル選択・外部通信は行いません。取得完了だけでは画像の準備も検索も開始しません。

サンプル5枚 → 検索例 → 検索 → 画像をクリック

入力と結果を並べて見る

モデルサイドバーに加え、作業領域を入力とギャラリーに分けます。画像の選択から検索までを左で進め、右には画像を大きく並べます。狭いウインドウでは入力と結果を縦に切り替えます。

元画像と全候補で確かめる

選択時も検索後も、画像をクリックすると元画像シートが開きます。結果が0件でも全候補に切り替えられます。入力中の語句と実行済みの検索語を分けて表示します。

処理と準備を区別する

モデル取得の状態は見出しの下、モデル準備・画像索引・検索・停止は入力の下へ。未取得でも説明とモデル情報は開けます。ファイル・画像・入力・実行は共通で無効化します。

既存画面との対応　ImageSearchViewの画像選択、サンプル5枚、9つの検索例、loading / indexing / searching / stopping、結果と0.67以上の既定表示、全候補、秒数、失敗詳細、OriginalSearchPhotoの元画像・開けない状態を保持しています。50枚上限、不透明な静止画／4,000万画素、検索語128トークンのエラーも含みます。モデルフォルダ選択と再読み込みは共通のモデル管理へまとめる提案です。
確認待ち　最初の画像選択時にモデル準備を進める導線、共通モデル管理との接続、入力と結果のセッション保持は実装時の確認が必要です。HTMLのサイドバーは選択中のモデルを抜粋し、他モデルの画面は扱いません。モデルの再準備は既存のloadと同様に選択画像・結果をクリアし、検索語を残します。
HIGとの対応　モデル選択と詳細を分け、サイドバー表示の切替、適応するギャラリー、キーボード検索、短い元画像シートを用意。標準のNSOpenPanel、NavigationSplitView、ツールバー、VoiceOverの動作は実装時に別途確認します。
