会話デモ

Chatで質問する。Workで調べて、メモにまとめる。

このデモについて

ChatとWorkは同じ会話画面で切り替えます。資料を使う場合はWeb・ローカル資料を選び、集めた資料から1回の回答を作ります。履歴はその会話に記録されたモデルで再開します。モデルが見つからない履歴も本文は閲覧できます。

何を話しましょうか。

質問や相談を入力してください。必要に応じてWebを調べます。

Chat · 必要に応じてWeb検索
入力を送信するまで、推論は始まりません。

主役はモデルと会話

モデルは左で選択。Chat / Workは会話内のモードとして扱い、二重のモデル選択をなくします。

資料は会話のそばに

RAGの選択と使用した資料は補助画面に集約。既存にない資料の登録・削除機能は追加しません。

途中や失敗も消さない

停止、トークン上限、文脈満杯、保存失敗、旧履歴の閲覧専用状態を確認できます。
