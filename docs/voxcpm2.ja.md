# VoxCPM2 の音声合成のデモ

[ホーム](../README.ja.md) · [English](voxcpm2.md)

Mac のアプリの **VoxCPM2** の画面は、[openbmb/VoxCPM2](https://huggingface.co/openbmb/VoxCPM2)(Apache-2.0)の FP16 の Core AI の bundle で、文章から音声を生成します。文章には声の説明を書き添えられます。サイドバーの **VoxCPM2** の見出しから bundle を取り込み、その下の行を選んで、生成・再生・停止と、48 kHz・モノラル・Float32 の WAV の保存を行います。iPhone の版はありません。

bundle は公開していないので、アプリからはダウンロードできません。[変換の手順](../Tools/Conversion/recipes/voxcpm2/README.md)で作ります。変換の照合・時間・メモリの実測は[変換の検証記録](validation/voxcpm2-conversion-20261117.md)にあります。聴いたときの品質と、通常の画面での操作は、まだ受け入れの確認が済んでいません。

## bundle を取り込む

1. 変換の手順は 3 つの構成を書き出します。`fp16` のフォルダを選びます。アプリが受け付けるのはこの構成だけです(固定した 22 ファイル、合計 4,677,413,664 バイト)。FP32 のフォルダと、projection だけ FP32 の FP16 のフォルダは拒否されます。
2. 選ぶ前に、フォルダからほかのもの(Finder が作る `.DS_Store` など)を消します。余分なファイル、変わったファイル、欠けたファイル、リンクがあると拒否されます。これらと別の構成のどれでも、サイドバーには同じ文(「モデルファイルが必要な形式と一致しません。」)が出ます。
3. **VoxCPM2** の見出しの「モデルを取り込む」(フォルダに＋の印)を押して、フォルダを選びます。Models はフォルダをアプリのモデルの領域へ写し(約 4.7 GB)、全ファイルの大きさと SHA-256 を確かめます。選んだフォルダは変えません。後でモデルを開くときに、アプリのキャッシュに検査済みの複製をもう 1 つ作るので、両方の空き容量を用意します。

後の版のアプリで固定したファイルの一覧が変わると、前に取り込んだものが取り込み済みと表示されたまま、開くと誤りになることがあります。見出しから削除して、新しいフォルダを取り込み直します。

## 画面を使う

1. **VoxCPM2** の行を選びます。画面は取り込んだモデルを自分で開き、全ファイルをもう一度確かめます(モデルは動かしません)。取り込んでいなければ、サイドバーの見出しから取り込むよう案内します。
2. 例文を選ぶか、文章を入力します。声の説明は、文の先頭に半角の括弧で書きます。例: `(A young woman, gentle and calm voice)確認が終わりました。`。説明のための別の入力欄はありません。例文は、説明のない文、説明つきの日本語の文、説明つきの英語の文です。
3. 文は、空白を整えて複数の漢字の token を分けた後の text token が 144 個までです。長い文は切り詰めずに拒否します。モデルが読めない文字を含む文も拒否し、その文字を消すか置き換えるよう案内します。
4. **Generate speech** を押します。モデルを開いた直後、画面に戻った後、失敗の後の最初の生成には、モデルの資産を読み込む時間も入ります。音声が終わる前にモデルの長さの上限に達した生成は誤りとして表示し、音声を返しません。seed は符号なし 64 ビットの整数で、最初の値は `1708` です。
5. **Play**・**Stop**・**Save WAV…** は Irodori の画面と同じです。保存の既定のファイル名は `voxcpm2-speech.wav` です。

画面を離れると、進行中の処理を止めてモデルを解放します。画面を表示している間は、見出しからモデルを削除できません。VoxCPM2 と Irodori の画面は、文・seed・音声・モデルのフォルダを別々に持ちます。

## 含まないもの

参照音声(声のクローン)、逐次の再生、声の説明の専用の入力欄、音量をそろえる処理、ダウンロード、ほかの構成の bundle、iPhone。

## 確認

- `swift test --package-path CoreAISamplesKit` は、カタログ(`MacDemoCatalogTests`)、生成のボタンの条件(`SpeechGenerationGateTests`)、画面の Store(`SpeechStoreTests`)、文の誤り(`VoxCPMTextErrorTests`)を確かめます。アプリの `--check-localization` は、サイドバーとカタログの対応と、日本語の文字列を確かめます。
- `VOXCPM2_TOKENIZER=/path/to/fp16 swift test --package-path CoreAISamplesKit --force-resolved-versions --filter SpeechRuntimeTests.VoxCPMTokenizerTests` は、例文の text token の数も数えます。読むのは `tokenizer.json` だけです。
- `AGENTS.md` にある機能全体の試験は、共有の heavy-job ロックの下で動かします。FP16 の bundle を一時のモデルの領域へ取り込み、利用の lease を取り、本番のサービスと Store で全部の例文を生成し、WAV を確かめ、停止し、lease を返し、選んだフォルダが変わっていないことを確かめます。
- これらの確認は、聴いたときの品質と通常の画面での操作を保証しません。それらは本人の受け入れの確認として残っています。
