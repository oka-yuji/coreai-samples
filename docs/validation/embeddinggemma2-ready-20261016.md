## Search policy and the retained failure

[The evaluation plan](../../Tools/Embedding/search-evaluation.json) separates six calibration queries from six held-out queries before scoring. The [frozen policy](../../Tools/Embedding/search-policy.json) rounds the midpoint between the lowest relevant calibration top score (0.7504983505) and highest unrelated calibration top score (0.5894985895) to **0.67**. Calibration achieved 6/6. The policy was fixed before the held-out run, and the evaluation JSON hash is recorded.

On the five similar refrigerator images, held-out queries include paraphrases and unrelated subjects. Two relevant queries display the expected image, and all three unrelated queries display no close matches. The remaining relevant query, `トマトと白いチーズでカプレーゼを作れそうな写真`, ranks the correct image first but scores about **0.660**. It is hidden by the default policy. It remains in the denominator, and the threshold was not lowered afterward. **Show all candidates** reveals it. This limited result is not a universal relevance/confidence calibration.
