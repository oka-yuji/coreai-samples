# Chronos-2 fixed NYC demo verification

Issue [#545](https://github.com/oka-yuji/coreai-samples/issues/545), 2026-11-12 (JST). [Structured results](results.json).

The production Models, Store, session and service path passed all 60 fixed scene/zone cases and 20,160 raw quantile values against the pinned official FP32 reference. Every scalar met `abs(actual-reference) <= 1e-4 + 1e-4*abs(reference)`. Closing the session left zero model leases. The drawing adapter in this test is a test adapter; normal Mac UI was checked separately.

## Data and identity

The three January 2025 scenes use 20 Manhattan taxi zones. Each model input contains 1,008 half-hour pickup counts; the native output preserves all 21 quantiles and 16 steps. Eight aggregate/geometry/source files regenerated byte-for-byte from the pinned TLC Parquet, zone archive and lookup table. An independent raw-row aggregation matched all 61,440 history/truth values. `Tools/NYC/verify.py` also passed all nine bundled files and 39 precomputed frames. Raw trips are not bundled.

The precomputed cache was regenerated with the current graph, not the former private application's model. Its 780 native requests / 262,080 raw values passed the same frozen tolerance before selecting 9,360 displayed values. No cache timing is presented as a device measurement.

## Normal Mac application

The normal sidebar opened the interactive precomputed preview with no inference. After choosing the prepared model and explicitly requesting prediction, the actual model produced the displayed forecast. For Friday 17:00 in Times Sq/Theatre District, the last observed count was 95, the next forecast median was 120 and its 10–90% range was 102–146. The later 18:00–18:30 interval displayed 128 and 105–158. Advancing the simulation by 30 minutes revealed the observed 130 while retaining the forecast's 17:00 origin. Leaving for another demo and reopening returned to the initial precomputed state without an old forecast.

Source and managed bundle hashes remained unchanged. The app was closed before the shared model lock was released. These observations establish the stated Mac route, not a performance benchmark or user acceptance.

The final display check confirmed Japanese guidance and quantile labels, and explicit chart accessibility labels for New York half-hour intervals on a device configured for Tokyo. Setting only the SwiftUI calendar/time-zone environment did not correct the chart's automatic accessibility dates. Explicit mark labels fixed that behavior. Compiler-extracted localization keys also exposed literal `%` escaping in interpolated text; the corrected catalog matches all 49 extracted static keys.

## Lifecycle and platform boundaries

The Mac preview retains model classification, summary and expandable preparation guidance. The expanded guide and forecast share one scroll view; scrolling to the final content was checked in the normal app. On iOS, the existing host owns vertical scrolling, with no nested Chronos scroll view. The device-processing label explicitly includes model preparation when needed. All ten catalogs contain 1,393 keys with no missing translations or placeholder mismatch.

CPU tests cover elapsed-only history, unchanged forecast origin, stale completions, cancellation, delayed release, owner changes, permission revocation and managed identity validation before model construction. The shared iOS host now permits interaction only for explicitly opted-in previews; older descriptors retain their disabled-preview default.

Mac Release and signed iOS Release builds passed. The iOS artifact passed signature verification and contains both file-sharing keys. No physical iPhone inference or normal iPhone UI acceptance was performed. Package tests intentionally skip model checks unless explicitly enabled. The reference comparison ran under the shared heavy-job lock using `ChronosDemoNativeTests.fixedScenes` at source commit `06e010133afd10d0d31532cfa804b97818944b30`; subsequent changes in this unit affect presentation and evidence only.

Host conditions: Apple M5 Max, 137,438,953,472 B RAM, macOS 27.2.1 (26B131), Xcode 27.2 (27B52), Swift 6.4.2, SDK 27.2. The model test used the Debug package; GUI checks used the Release application. Power, thermal state, memory and controlled latency were not measured. This is a legacy functionality record with those omissions retained.
